# joelduran.com

Personal portfolio site for Joel Duran, AI Product Manager. Built with Next.js, TypeScript, and Tailwind CSS. Deployed to GitHub Pages via GitHub Actions.

## Commands

```bash
npm run dev    # Local dev server at http://localhost:3000
npm run build  # Static export to out/
npm test       # Run unit tests
npx serve out  # Preview production build locally
```

## Deploy

Merges to `main` trigger a GitHub Actions workflow that builds the static site and deploys to GitHub Pages at [joelduran.com](https://joelduran.com).
